# محاكي تجميع الحاسوب

واجهة عربية لمحاكي تجميع حاسوب قديم، مع موسوعة للقطع وعرض للصور المتاحة من زوايا مختلفة. يستخدم الموقع Ruffle لتشغيل ملفات SWF محليًا في المتصفح.

## التشغيل

يتطلب المشروع Node.js إصدار 18 أو أحدث. من داخل مجلد المشروع:

```sh
npm start
```

افتح `http://localhost:8080`. يمكن تغيير المنفذ باستخدام متغير البيئة `PORT`، ويمكن تحديد واجهة الاستماع باستخدام `HOST`. الخادم يستمع افتراضيًا على جميع واجهات الشبكة؛ لا تعرضه للإنترنت مباشرة دون إعداد حماية وتحكم بالوصول.

على Windows يمكن أيضًا تشغيل `start-server.bat`. لتجربة الموقع من هاتف على الشبكة المحلية، افتح عنوان IP الخاص بالكمبيوتر مع المنفذ 8080، وتحقق من إعدادات الشبكة والجدار الناري.

## فحص الصياغة

```sh
npm run check
```

لا يحتاج تشغيل المشروع إلى تثبيت حزم npm خارجية. يجب الاحتفاظ بالمجلدين `PC` و`ruffle-local` لأنهما يحتويان على ملفات المحاكي وأصوله.

## النشر

يمكن رفع الملفات إلى مستودع GitHub. يتطلب التشغيل المؤكد استضافة تدعم Node.js لأن الخادم يعالج اختلاف حالة الأحرف وبعض المسارات القديمة لملفات Flash. GitHub Pages استضافة ثابتة ولا تشغّل `server.mjs`، ولم يُتحقق من توافق جميع مراحل المحاكي معها. يمكن تشغيله على خدمة Node.js باستخدام الأمر `npm start` ومتغير `PORT` الذي توفره الخدمة.

تعتمد بعض المراحل على ملفات SWF كبيرة وقد تستهلك ذاكرة مرتفعة على الجوال. عارض القطع يستخدم صور الزوايا المتاحة؛ لا تتوفر زوايا متعددة لكل قطعة، وهو ليس نموذجًا ثلاثي الأبعاد حقيقيًا.

## حقوق المحتوى

يتضمن المشروع ملفات وأصولًا قديمة تحمل علامات Cisco وملفات Ruffle. تحقق من ملكية الأصول وتراخيصها وحق إعادة توزيعها قبل نشر المستودع علنًا. لا يمنح هذا المستودع ترخيصًا للمواد المملوكة لأطراف أخرى.
